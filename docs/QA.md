## UI参考画像との照合

`docs/ui-concept.png` とIABスクリーンショットを `view_image` で直接比較。PCは参考と同じ1536×1024。

| 比較点 | 結果・修正 |
|---|---|
| レイアウト | 左に大きな3D、右に白い構造リスト。低いPC画面の見切れを、3D領域の高さ固定と追従で修正 |
| 配色 | 白ヘッダー／白サイドバー／冷たい青灰色の背景／tealの選択表示を維持 |
| 文字階層 | ブランド、教材見出し、構造名、英語、説明、補助の順。日本語システムSansで実装 |
| 操作部品 | 視点ボタン、4分類、色点つきリスト、目アイコン、不透明度スライダーを実装 |
| 3D素材 | 参考画像の空欄を実際のBodyParts3Dに置換。架空の生成解剖画像を用いていない |
| モバイル | ビューを上、構造リストを下。横はみ出しなし。タッチ対象44px以上（主要操作） |
| 文言差分 | 提供元の誤記をDBCLSへ修正。FAQを追加せず使い方・出典へ集約。透明度の意味を不透明度として明示 |

構図・配色・操作部品は設計参考に沿って確認済み。完全なピクセル一致を求めるものではなく、医学的正確性・実操作のための上記差分を採用。
