# v2 血流表示の設計 — 2026-09-29

## 医学的根拠と表現の範囲

経路の順序は [NHLBI: How the Heart Works — How Blood Flows through the Heart](https://www.nhlbi.nih.gov/health/heart/blood-flow)（ページ更新2025-06-25、確認2026-09-29）を確認。記載された心腔・弁・血管の接続を独自コードで可視化し、同ページの動画・画像・モデルは複製していません。

上・下大静脈は右房へ入り、三尖弁・右室・肺動脈弁を経て肺動脈へ。左右上下の肺静脈は左房へ入り、僧帽弁・左室・大動脈弁を経て大動脈へ向かいます。肺・全身は今回のモデル外であり、直接つなぐ線は表示しません。

**実測データではなく模式的な経路（推定）**です。実際の心内流線・血管中心線・血球形態・心拍周期・弁開閉・流速・流量・圧・乱流を再現しません。各区間の粒子は独立して繰り返し、端で小さく消えて再出現します。同一血球を追跡するシミュレーションではありません。画面の矢印と構造名の順序から全体の接続を学ぶための表現です。

## 座標と出典

v1のBodyParts3D GLBは変更なし。肺・血管・弁などの新しい解剖形状は作成していません。血流ガイドはGLB各部品の境界箱から選んだ点を通る開いた曲線です。位置割合は `src/flowPaths.js` に明示した設計上の推定値で、セグメンテーションによる中心線抽出ではありません。したがって血管や弁尖表面との厳密な接触・内腔内への完全な収まりは保証しません。

血流順序に沿う16区間を作成。曲線はThree.jsのcentripetal CatmullRomCurve3を使用。元メッシュの遮蔽を受けない透視ガイドとして重ねるので、前面からも後方の経路が見えます。色は酸素の少ない血液を青、多い血液を赤に区別する教育用配色です。

モデル利用条件・取得日・加工履歴はREADMEと `public/models/manifest.json` を参照。追加コードはMIT。血流ガイドの追加でBodyParts3Dのライセンスが変更されることはありません。

## 操作・性能

- 3粒子×16区間＝48粒子、16矢印。左右それぞれInstancedMesh、簡素なガイド線。追加テクスチャ・外部サービス・モデルダウンロードなし。
- 再生中のみ連続描画。一時停止、別モード、非表示タブでは血流時間を進めず、復帰時も大きく飛ばしません。
- 0.5／1／2倍は表示速度。1周期5秒は便宜的な反復時間です。
- prefers-reduced-motionでは自動再生せず、明示的な再生操作に対応。
- 描画負荷は機種で異なります。実機iPad Safariのfps・発熱・電池消費は未測定。
